                      !***** Student Management System *****! (Java)

-> Project Description

-> This Student Management System is a simple Java console-based application that allows users to add, view, search, update, and delete student records stored in a text file.

->Features:

1. Add Student

* Add new student details such as Student ID, Name, Age, Department, and Percentage.

* Validate user inputs before saving.

* Prevent duplicate Student IDs.

2. View All Students

*Display all student records stored in the student.txt file.

* Read student details using BufferedReader.

5. Search Student

* Search for a student using Student ID.

* Display the matching student's details.

* Show an error message if the Student ID is not found.

4. Replace / Update Student

* Search for an existing student using Student ID.

* Allow users to select which information they want to update:

   -> Name

   -> Age
    
   -> Department
    
   -> Percentage

* Validate the entered values based on their data types.

* Update the selected student's information and save the changes back to the file.

* Throw a custom exception if the Student ID does not exist.

3. Delete Student

* Delete a student record using Student ID.

* Keep the remaining student records unchanged.

* Display an error message if the Student ID is not found.

-> Technologies Used

* Java

* OOP Concepts

* ArrayList and Collection Framework

* File Handling (FileReader, BufferedReader, FileWriter, BufferedWriter)

* Exception Handling 

* Scanner Class

-> Data Storage

* Student records are stored in student.txt.

* Data is stored in comma-separated format.

* File handling is used to read, write, update, and delete student records.
